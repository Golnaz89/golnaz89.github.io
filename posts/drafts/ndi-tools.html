NDI Tools: The Free Tech That Changed How We Do Video

If you've ever wondered how professional studios send video signals across a network without running HDMI cables everywhere, the answer is probably NDI. And the wild part? It's completely free.

What Is NDI?

NDI (Network Device Interface) is a protocol invented by NewTek that allows video sources to be shared over a standard ethernet network. Instead of running physical cables between devices, you can send broadcast-quality video over IP. It's low latency, high quality, and works with pretty much everything.

The genius move? NewTek decided to give it away for free. They released the NDI Tools suite at no cost, which means anyone can download and start using it. This decision basically made NDI the standard for network-based video production.

It's Everywhere

Once you start looking for NDI support, you'll find it everywhere:

  • OBS Studio – The go-to free streaming software has built-in NDI support via plugin. You can send and receive NDI sources directly.
  • Desktop apps – NDI Tools includes Screen Capture and Webcam Input, so you can turn any screen or camera into an NDI source.
  • Adobe Creative Cloud – Premiere Pro and After Effects can output via NDI, making it easy to preview on other devices or feed into live productions.
  • TriCaster – This is the big one for us. Our studios run on NewTek TriCasters, and NDI is deeply integrated. Every input and output can be an NDI source.

The KVM Switch You Didn't Know You Needed

Here's a use case that blew my mind when I first discovered it: NDI can act as a KVM switch over your network.

With NDI Tools, you can view and control remote computers. Need to see what's on a machine in another room? NDI. Want to control it without walking over there? NDI. It turns your network into a virtual KVM system without any extra hardware.

For studio setups where you have multiple machines doing different jobs, this is a game changer. No more swapping cables or buying expensive KVM switches.

Using NDI with Microsoft Teams

This is where it gets really interesting for hybrid and remote productions. Microsoft Teams supports NDI output, which means you can pull individual participant video feeds directly into your production software.

But there's a catch: you need a Microsoft 365 Business account, and you have to enable NDI Broadcast Tools in the admin portal. It's not on by default.

Henk Boelman wrote an excellent guide on setting this up. If you're trying to do online events with Teams, NDI, and OBS, his article walks through the entire process step by step. Highly recommend bookmarking it.

Why This Matters

NDI democratized professional video production. Before NDI, sending video over IP required expensive proprietary systems. Now, anyone with a decent network can build a multi-camera studio setup using free tools.

For us, it means flexibility. We can add sources, route signals, and integrate remote participants without rewiring anything. The TriCaster sits at the center, but NDI connects everything around it.

If you're doing any kind of video production and you haven't explored NDI yet, download the free tools and start experimenting. You'll wonder how you ever worked without it.
