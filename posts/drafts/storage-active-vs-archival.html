Active vs Archival Storage: How We Store Petabytes on Pennies

Video files are big. Raw footage is bigger. And when you've been producing content for 15 years, storage becomes an existential problem. Here's how we solved it.

The Two Storage Problem

In video production, you have two very different storage needs:

  1. Active storage: The stuff you're working on right now. Needs to be fast, accessible, and collaborative.
  2. Archival storage: Everything you've ever made that you might need again someday. Needs to be cheap and reliable.

These are fundamentally different problems with fundamentally different solutions.

Our Archival Journey

The Old Way: SNS EVO

We used to run an SNS EVO server for our archive. It worked. It was reliable. It was also expensive. Really expensive. We're talking significant ongoing costs for hardware, maintenance, and the ever-present fear of drive failures.

I actually wrote about our setup on their platform: [LINK TO ORIGINAL BLOG]

The New Way: Azure File Sync

Now we run our own Windows Server that syncs to Azure Blob Storage. The game-changer? Azure File Sync.

Here's the magic: files that haven't been accessed in a while get tiered to the cloud automatically. On our local server, they show up as placeholders. When someone needs an old file, it pulls down on demand. The stuff we use regularly stays local and fast.

The cost difference is absurd. We're talking pennies on the dollar compared to dedicated media storage solutions. For archival footage that might get accessed once a year? This makes so much sense.

Active Storage: Frame.io

For active projects—the stuff we're editing right now—we use Frame.io.

The Adobe and Azure partnership here has been huge. Cloud-native editing workflows, real-time collaboration, AI-powered features for searching and organizing footage. It's built for creative teams who need to move fast.

Why This Works for Us

  • UI that creatives can use. Drop-down menus. Visual interfaces. Drag and drop. My team are video producers, not sysadmins.
  • Built for collaboration. Comments on frames, version tracking, approval workflows.
  • AI organization. Auto-transcription, searchable footage, smart tagging.

The CLI Problem

Here's a rant: so many powerful tools require command-line interfaces. And look, I get it. CLIs are powerful, flexible, scriptable. Engineers love them.

But creative teams? We're visual people working on visual problems. We need to see our footage, scrub through timelines, drag things around. Asking an editor to run terminal commands to access their files is a non-starter.

Maybe one day there will be a bridge—powerful cloud tools with interfaces that creative people can actually use without calling IT. We're getting closer. But we're not there yet.

The Bottom Line

Storage Type Our Solution Why
Archival Windows Server + Azure Blob (File Sync) Cheap, reliable, tiered
Active Frame.io Fast, collaborative, creative-friendly

If you're drowning in storage costs, seriously look at cloud tiering. The math works out. And your future self will thank you when you can actually find that footage from 2019.
